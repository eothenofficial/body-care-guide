# 历史需求与本轮覆盖矩阵

本表保存讨论中的具体问题，避免扩章时漏项。它区分本轮正文、跨章衔接和后续选题，不将待讨论的设想写成已经证实的结论。当前范围为五官与头皮头发，眼睛新增视力板块；其他身体篇章仍按全书SOP保存选题。

## 所有章节共同遵守的要求

| 用户要求 | 落实方式 |
| --- | --- |
| 普通年轻人缺少护理常识，男女都要能用 | 面向年轻成人写；解释术语，按症状、场景与实际需求选择 |
| 全面，但不能泛泛而谈 | 单元有递进关系；每条解决一个真实决定，不靠篇幅或条数充数 |
| 标题让读者知道该做什么 | 情况加动作，必要条件写进标题，避免只有病名的目录 |
| 读者会因自己的症状或想买的产品点进来 | 独立摘要与症状、用品、场景搜索共用同一正文 |
| 长辈土方法、流行营销都要核实 | 逐项查证，不按流行、传统或品牌价格直接判定 |
| 明确推荐，不只定义产品再转给医生 | 给起步选择、理由和改选条件；需检查时交代检查怎样改变方案 |
| 保证科学性和推导正确 | 核具体人群、干预、结局、时间、偏倚；不以机构名替代论证 |
| 机构和一手证据足够权威，保持时效 | 不用个人号、营销或旧价目承担关键判断；新旧研究按用途判断 |
| 没有可靠成本资料就删 | 无可靠金额不写金额，成本无信息量则不展示；不造假设价 |
| 引用统一、学术而正确 | Vancouver顺序编号，核作者、正式年卷期页与DOI，机构网页无DOI不补造 |
| 避免知识的诅咒 | 每条可单独读懂，陌生名词首次出现时解释用途或原理 |
| 说人话、少车轱辘话 | 结论先行，理由接住动作；成本、收益、证据、备注各有功能 |
| 主页是标题加摘要 | 独立summary，约两三句；列表最多五行，详细页才放表格与全文 |
| 可打开、可传播、可维护 | 一个数据来源生成网页、离线HTML、Markdown和JSON；保持稳定ID与审计记录 |
| 持续扩展，不做一次性文章 | 保存SOP、覆盖矩阵、来源与复核记录；本轮完成五官稿，确认后再扩全身 |

### 鼻子与耳朵

| 原始问题 | 本轮应覆盖 |
| --- | --- |
| 鼻毛是否修、怎样修、能否拔或蜡脱 | 修剪外露部分与防止损伤，用品操作边界 |
| 经常揉鼻、掏鼻孔、鼻屎结硬 | 干燥与清洁习惯，不能无限抠挖或用力擤鼻 |
| 鼻部黑头、毛孔、粗糙和“油脂粒” | 鼻章提供入口，皮肤章区分皮脂丝、黑头及需要检查的其他疙瘩 |
| 常流鼻血，怎么避免和急救 | 前倾压迫的正确部位、持续时间及反复/严重出血的分流 |
| 鼻炎、洗鼻壶、盐水喷剂和通鼻喷雾 | 按症状与需求分选，安全用水、器具及药物类别解释 |
| 不要掏耳朵是常识还是伪科学 | 耳道自洁、外耳清洁，棉签/挖耳勺/采耳/耳烛分别判断 |
| 耳屎堵、进水、疼痒流液 | 先分堵塞与炎症，软化/冲洗的适用与不适用条件 |
| 耳机、噪声、耳鸣和听力改变 | 音量与时长、防护、突发听损及时处理；不靠补剂拖延 |
| 飞行闷堵、耳洞与耳饰 | 作为年轻人生活场景补充，不扩成完整耳科教材 |

### 嘴唇与完整口腔

| 原始问题 | 本轮应覆盖 |
| --- | --- |
| 润唇膏、唇膜是不是智商税 | 保湿配方、实际体验和外观价值，避免刺激；不以价格推疗效 |
| 舔唇、撕皮、用手摸唇 | 改掉加重损伤的动作，给可替代行为 |
| 反复红裂、口角裂、唇疱疹 | 不把所有干裂都当缺水或缺维生素；给区别、用药类别与检查条件 |
| 唇部防晒、口红和过敏 | 防护、补涂、停可疑产品与唇妆选择 |
| 电动牙刷是不是智商税 | 与手动比较可实现的清洁和执行负担，含氟牙膏与方法优先 |
| 不爱用牙线是否正确、水牙线能否代替 | 牙线、间隙刷和冲牙器的适用，出血、正畸与牙龈状况 |
| 漱口水有无必要、含酒精还是无酒精 | 按活性成分和用途选择，不按酒精有无给全部商品排疗效 |
| 氯己定及“长期杀菌” | 治疗用途、疗程和副作用，不当普通长期保养 |
| 牙龈呵护、洗牙、牙石和牙周病 | 出血与持续异常的检查，日常清洁和专业处理如何配合 |
| 刷舌苔、口臭 | 温和可选清洁，不把舌刮当慢性口臭的通用解决方案 |
| 经常口腔溃疡等看似小问题 | 疼痛自护、反复与不愈红旗；不默认补维生素或自行确诊 |
| 蛀牙、敏感、酸性饮食 | 早期信号、产品类别、暴露频率与需要治疗的条件 |
| 美白牙贴、牙粉、瓷贴面与烤瓷冠 | 着色与漂白、磨耗、敏感、不可逆磨牙和后续维护分别解释 |
| 智齿要不要拔 | 疾病和邻牙风险、保留随访，不一律拔或一律保留 |
| 成年正畸与美容选择 | 正规评估、器具区别、口腔卫生及保持，不能承诺人人适合某牙套 |

### 面部皮肤、美妆和美容

| 原始问题 | 本轮应覆盖 |
| --- | --- |
| 痘痘、斑、疙瘩、皮肤粗糙 | 痤疮分层、痘印/痘坑、色斑和异常病变分开处理 |
| 防老化、保持状态，不能只靠涂抹 | 日晒、清洁保湿、饮食睡眠等相关习惯；不包治所有问题 |
| 黑头、皮脂丝、毛孔、脂肪粒等俗称 | 先说明可分辨范围与不同处理目标，不做“全清零”承诺 |
| 哪些护肤成分有对应证据 | 维A类、过氧化苯甲酰、壬二酸、水杨酸、烟酰胺等按目标与耐受讨论；明确用药及孕期边界 |
| 面膜、喷雾、修复、抗糖和胶原补剂 | 体验、短期指标、临床收益及营销外推分别评价 |
| 敏感、反复红痒、玫瑰痤疮、脂溢皮炎 | 不把持续刺激叫排毒期，写具体起步和升级条件 |
| 眼霜、眼下毛、黑眼圈、浮肿、凹陷和按摩 | 按不同成因与目标取舍，普通保湿不冒充填充或治疗 |
| 剃须、细毛和仪器 | 皮肤损伤、用品与具体适应证，不把一类光电研究借给所有设备 |
| 化妆、美妆、卸妆、底妆和工具 | 妆效与治疗分开，配方耐受、清洁与污染预防；不强制所有人叠加同一套流程 |
| 激光、肉毒、填充和其他医美 | 本轮覆盖医美咨询、填充风险与设备警示入口；新增肉毒目标、证据与风险条目，仍不声称已完成所有医美项目或品牌评测 |
