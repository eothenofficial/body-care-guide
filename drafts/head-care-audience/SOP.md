# 身体护理指南全书规划与调用SOP

版本：2026-10-29。依据完整需求讨论、用户原始口述、认可的五官稿及2026-10-29新增视力、头皮头发、耳饰清洁、正畸与人群分层要求制定。本文件是维护与写作标准，不是临床认证。用户写作指南原文完整保存在[参考原稿](references/写作风格校准SOP_用户提供原稿.md)，未改写其内容。

## 1. 读者与范围

面向中国年轻成年人，男女都要能用，尤其是过去缺少系统身体护理教育的人。全书最终从头到脚，围绕健康、舒适、外观、便利与消费选择组织；不是人人都要照做的保养任务清单。

2026-10-29当前授权正文为：既有眼睛、鼻子、嘴唇、完整口腔、耳朵、面部皮肤，加头皮与头发；眼睛新增独立视力板块；口腔的阅读导览重组为“牙齿与牙周”和“嘴唇与口腔黏膜”，耳朵补耳廓耳后清洁、穿孔、耳饰及耳夹。头发头皮现在纳入这次合订稿，未来仍可归入毛发篇，不能因为当前放在五官扩展稿中就锁死全书目录。其余身体部位保存研究题目，未授权本轮一并写成正文。

年轻成年人仍是核心读者；本轮明确扩展儿童、青少年与老年阅读入口，包括儿童近视与换牙、青少年正畸、成年人正畸及老年缺牙修复。不能因此把既有成人正文自动标为全龄适用，不能把儿童试验移植成年读者。没有专门核对的人群要如实标明，年龄不取代发育阶段、检查结果与具体产品条件。身体状态可能与精力、情绪和外观有关，但不能预设所有心理或认知问题都由身体状态造成，也不能把护理自动写成延寿。

## 2. 先把读者的问题组织成目录

使用“篇—部位章—主题单元—行动条目”。每章和每个单元有简短导览，说明它帮助读者作什么决定；按照识别困扰、基础处理、产品或专业服务选择、日常预防的关系组织，顺序可按部位调整，不机械套模板。

条目有一个主要归属。症状、用品、外观目标和生活场景提供交叉入口；相关内容互相链接，不重复写三套判断。鼻部黑头与皮脂丝主要放在皮肤章，鼻章引导过去；眼周护肤与眼表疾病分别处理。

标题包含读者遇到的情况和具体动作，范围不得比正文或证据更宽。例如写“眼里进灰先别揉，冲洗后仍有异物感就检查”，不只写“眼部健康知识”。标题中的就医分流不能在后文被轻症观察条件覆盖。

每章应同时检查以下选题：

- 容易被当成“小毛病”的疾病或异常表现，以及必须及时处理的信号。
- 正确的起步做法、治疗或护理类别、怎样判断是否需要升级处理。
- 长辈传下来的习惯和土方法，分别核实依据，不能因“传统”或“流行”就判真伪。
- 消费品、药品、保健品、化妆品、美容设备和医疗操作的实际用途与限制。
- 日常场景下的预防，包括屏幕、运动、游泳、清洁、化妆、睡眠、饮食等与本部位相关的行为。

## 3. 研究的是具体判断，不是收集权威链接

每个重要结论先明确：给谁、解决什么、与什么比较、持续多久、实际测量什么结果。先查适合问题的现行指南、系统综述和机构临床说明，必要时回到原始人体研究。

来源优先顺序依问题确定：

1. 临床处理与分流：国家卫生机构、专业学会正式指南或共识、专科医院现行说明。
2. 疗效与风险比较：高质量系统综述及原始人体研究，核对人群、设计、结局与偏倚。
3. 合规、适应证和产品安全：当地监管机构及其原始说明书、注册或警示文件。
4. 操作和习惯：专业组织或正规医院的一手指导；不能把常规护理指南冒充量化疗效试验。

不以个人科普号、商业问答、媒体转述、品牌宣传、搜索摘要或历史价目表承担关键临床推荐。产品官网只可核型号、标签和实际宣称；不能单独证明疗效。机构声望与网页域名不替代逐项核查，权威机构页面也可能过宽、陈旧或与其他证据冲突。

逐条记录支持范围、不能支持什么、实际读取深度及核对日期。读摘要就写摘要；打开全文但只读有关段落，就写具体段落。不能声称已穷尽最新研究、重新分析个体数据或完成医生审核。

旧的原始试验可用于说明该研究的实际结果，不能借旧试验断言现在的全部产品或最新指南。价格、在售型号、批准状态、药品属性与设备要求易变化，必须另核当前地区信息。发现撤稿、修订或指南更新时记录影响，不按年份机械删掉全部旧研究。

## 4. 证据怎样变成建议

正文须分清事实、推断与建议。证据允许时给出明确的条件性优先顺序，不能用“按个人情况”“咨询专业人士”省掉中间判断。需要检查时，说明要确认什么、结果如何改变方案。

禁止以下推导：

- 相关性写成因果；人体检查指标变化写成一定感觉舒服或长期防病。
- 原料、体外、动物、发束试验直接证明所有同名成品有效。
- 儿童结果移植成人，某款设计或剂量借给全品类，国外标签直接当中国规定。
- 相对风险、比值比、危险比和个人概率互换；例如 HR 0.87 不能直接译成死亡概率少13%。
- 没有找到可靠证据写成已经证明无效或骗局；有统计差异就写成值得购买。
- 将低维护负担形成的编辑选择，写成疗效头对头排名。

“有效但不适合某人”“效果不确定”“有用但溢价未证明更好”“明确有风险”“只提供妆效或便利”分别表述，不全部叫智商税。科学性优先于语气肯定；无法做到100%保证，不以更硬的口吻掩盖不确定性。

证据等级沿用项目自定 A/B/C，并非 GRADE：A为较可靠的直接临床效果证据，B为有限或间接人体资料，C为共识、机制或护理安全实践。评级针对具体结局；一条有多个依据时分别说明，安全分流为C也不降低紧迫性。

## 5. 写一条可独立阅读的建议

按“结论与动作 → 理由 → 具体选择或例子 → 改选、停止或升级条件”写。陌生术语在该条首次出现时解释用途或原理，不假设读者读过上一条。必要的专业深度来自准确的分支和推理，不来自术语密度。

| 组成 | 应完成的任务 |
| --- | --- |
| 标题 | 读者一眼知道该做或不该做什么，含必要条件 |
| summary | 单独编辑的一段纯文本，通常约110至170字、两三句，帮助选读；关键风险条件不被删掉 |
| 说人话 | 给出能执行的起步动作、选择理由和改选条件；需要时用比较表 |
| 成本 | 仅写可支持且有实际信息的费用、耗材、维护或时间；无可靠依据则省略此栏 |
| 收益 | 能改善的症状、功能、外观或便利及适用范围；不重复行动步骤 |
| 证据等级 | 具体判断的依据和确定性，编辑取舍另说明 |
| 来源 | 正文对应的Vancouver编号与可核验书目 |
| 备注 | 会改变行动的特殊情境，不再重述全部免责声明 |

列表只展示标题与summary，通常约3至5行，实际随屏宽变化；正文、表格和文献留在点开后的页面。摘要不放Markdown、竖杠、文献号或作者调研过程，也不增加正文没有的医学判断。

删除同义反复、模板化连接语和为每栏填满而写的套话。简单习惯可以短，复杂选择要把决定条件写足；不按固定条数凑规模。

## 6. 成本宁缺毋滥

不引用已无法代表当前收费的医院历史价目，不以单片价推双眼首年费，不编全国行情或假设价格。无法核实可靠的当前报价就删除金额；如果一栏只剩泛泛“需要投入”“可以省钱”，整栏省略。

正规说明书或指南能支持的操作时间、复查次数、耗材和维护负担，可作为实际投入说明，不伪装成经济学成本效益结论。若提供价格，必须同时核币种、地区、日期、单双侧或计费单位、包含项目及后续维护，且价格与临床证据分列。

为兼容既有JSON接口，六字段键可继续保留；省略成本时 `fields.cost` 为空字符串。网页、静态分享页、Markdown、打印均不显示空成本标题。读者不会看到“价格待核”式占位段落。

## 7. 统一引用与DOI

采用Vancouver数字顺序编码，同一来源重复引用沿用同号。显示文献号随合订本重排，条目ID与来源hash ID保持稳定；不能用文献号当永久链接身份。

期刊格式：

`作者前6人, et al. 文章题名. NLM期刊缩写. 年;卷(期):完整页码或文章号. doi:10.xxxx/xxxxx.`

作者不超过6人全部列出，机构团体作者照原刊；不为凑6人添加作者。保留姓名连字符与复姓。没有期号时不造期号，电子文章号不改成页码；在线先发与正式卷期年份区分，不将二者拼在一起。题名与DOI须指向同一篇论文。

机构网页格式：

`机构. 页面题名 [Internet]. 实际发布或更新日期（能确认才填） [cited 2026 Oct 29]. Available from: 原始URL`

预定复审日不冒充更新日，网站当前日期或搜索抓取日期不当发表日。普通机构网页没有DOI很正常，不能补造。

核对步骤：先对照期刊原页或PubMed题录的作者、题名、年卷期页，再核DOI；DOI统一写 `doi:10...`，另存 `doi` 与可点击 `https://doi.org/...` 以便复查。不要把一篇论文的DOI贴到相似题名上。格式检查通过只证明格式，不证明研究支持正文。

## 8. 审读与技术交付

先核临床判断和适用边界，再核目录、标题、摘要与正文是否一致，最后核语言、引用和阅读功能。至少安排独立编辑复核，重点检查药物、孕期、急症、不可逆操作及研究外推；AI复核如实标为AI，不改称临床医生签审。

同一结构化来源生成网页、静态分享页、离线HTML、Markdown与只读JSON。自动检查字段、稳定ID、摘要、全部引用、DOI格式、跨章链接、人群元数据和导出一致性；实际浏览检查列表无表格泄漏、详细页保留比较表、搜索和来源弹窗正常；再实测年龄输入、年龄段与男女侧栏的应用、清除、空结果、关闭与急症保留。

交付包含：可打开的本轮工作稿、正文与文献、选题覆盖矩阵、来源与引用审计、修改记录、这份SOP和可复用指令。保存旧版，不自动覆盖已发布的医学正文。不声称工程测试证明临床正确。按最近一次用户明确授权的范围写作；新增部位先确认题目，不能自行把选题池全部写成正文。已经获授权的扩展不重复索要许可。

| 跨篇生活方式 | 护理不仅是涂抹；生活习惯、饮食与状态 | 睡眠、饮食、运动、压力、烟酒和补充剂的共通基础；只在部位章解释确实有关的部分 |

体毛主要归毛发篇，私密篇链接过去；湿厕纸与擦拭主要归如厕篇；手足问题主要归手足篇；面部已有内容不在身体皮肤篇复制。美妆美容贯穿全书，不把妆效当医疗效果，也不把个人审美收益一概叫心理安慰。

三个边界保留待讨论：私密篇是否纳入避孕、性传播感染预防等基础性健康；活动篇是否包含完整体态与减重塑形；睡眠、心理与精力是否另立篇目。心肺肝肾等完整内科系统不自动纳入当前护理项目。

## 10. 眼睛新增视力板块

1. 读懂视力检查：1.0/5.0、裸眼/矫正视力、屈光度、散光、眼轴；数字分别回答什么，不能互换。
2. 分清看不清：看远或看近、重影、眩光与突然变化；普通验光、专科检查和急症的不同入口。
3. 验光、配镜和复查：电脑/主观/散瞳验光；瞳距、散光轴位；低配度数和不戴镜的说法；更换与复查条件。
4. 长期管理：成人进展、高度近视、儿童矫正和控制对照；不把不同人群的数据混用。
5. 摘镜与宣传：激光和眼内植入镜片ICL；目标、适用、风险和长期跟踪；眼保健操、训练、护眼贴或恢复视力课程究竟研究了什么结局。

将已有镜片选择正文接入这些单元，避免为一个主题写三份结论。不是每个单元都必须有相同条数。

## 11. 瘢痕疙瘩专题题目

以下是后续待研究的完整采样点，当前合订稿不展开：

1. 普通瘢痕、肥厚性瘢痕、瘢痕疙瘩、痘印与相似病变怎样区分，哪些需要检查确认。
2. 俗称疤痕体质能否凭一次留疤或测试判断；既往、家族、部位、损伤类型有什么意义。
3. 痤疮、手术、打孔、纹身、烧烫伤等场景怎样预防；开放伤口、已愈合伤口、既有瘢痕的研究和处理目标分别是什么。
4. 局部注射、硅酮凝胶或贴、压力、冷冻、激光、手术及联合方案的适用人群、症状/外观效果、复发和不良反应。
5. 用户说的“同位素浅放”具体是什么；核素敷贴、浅层X线、电子线等名称应怎样准确区分并核证，不能默认同一技术。
6. 生长因子、康复新液、祛疤膏/精油，研究的是伤口愈合还是既有瘢痕变平、症状改善、减少复发，能否支持具体宣称。
7. 哪些可以观察，哪些需要咨询；就诊科室、病史、照片、变化和既往治疗怎样准备；成功标准应包含读者重视的结果。

## 12. 从规划进入执行

工期依据第一组实际检索、写作与复核耗时估算，不按固定章数承诺月份；在允许的范围内可并行研究，但同一文件指定唯一整合者。内容正确性、推导与可读性优先于条数。

## 14. 按年龄和男女组织阅读，不能据此自动开方案

每条正文必须能独立读懂；人口筛选只是额外导览。先确定证据中的真实人群，分别记录研究适用范围、推荐限制与读者关注点。不能只看标题出现“儿童”“男性”就自动贴标签，更不能因为剃须、长发或化妆推断性别。

当前导览约定：child为0–11岁，teen为12–17岁，adult为18–64岁，older为65岁及以上；“18岁以下”同时匹配前两组。它们是界面分段，不是儿科、正畸、近视治疗或老年医学的统一界值。7岁首次正畸评估不等于7岁都戴牙套，18岁不是正畸截止线，65岁也不能单独决定是否种植。混合牙列、骨骼生长、牙周和全身状态等真正改变决策的条件写在正文，并给来源。

### 14.1 条目的人群字段

```json
{
  "audience": {
    "age_groups": ["child", "teen"],
    "sexes": ["all"],
    "scope_note": "儿童和青少年入口，供学生与照护者阅读；具体方案仍按检查与适用条件判断。",
    "safety_pin": false
  }
}
```

- age_groups与sexes只能填写实际核对过的阅读范围。sexes可为all、female、male；all不能再和其他值混填。通用内容在男性或女性筛选时都保留，不能为了制造筛选差异而虚构男女不同。
- scope_note说明范围与未覆盖的边界，不放新的医疗结论、处方或没有引文的年龄阈值。需要年龄分支时，在正文写“谁先做什么、为什么、何时换路”，各自对上证据。
- safety_pin仅标真正的急症入口；年龄与男女筛选不能隐藏它们。界面明确这是保留的安全入口，不把它显示成已经核对的儿童用药方案。症状搜索和部位导航仍可缩小主题，不强行将全部急症塞进无关搜索。
- 适用男性的某项药物，不等于女性只需把该条隐藏。若同条包含孕期或接触暴露等安全信息，优先保留通用入口并标清正文限制；后续拆分时为警示保留独立可达路径。孕哺、器官/解剖情况、激素治疗与具体病史按真实需要另外核查，不用男女两选项推断。
- 老条目缺人群资料时，兼容显示成人原稿且注明儿童/老年尚未专门核对；不得默认为全龄。当前新版本要求所有条目具有完整字段。

### 14.2 界面与输出验收

读者可输入0–120范围内的整数年龄，或选择年龄段，再选不限、男性、女性；具体年龄映射到导览段，系统不从年龄生成诊断、剂量或手术资格。输入非法时明确提示，不能悄悄截断或改写。打开侧栏、应用、清除、Esc关闭和焦点返回均须实测。显示当前条件与数量；本章尚无对应人群内容时如实说未系统整理，不能把成人内容伪装成匹配结果。

个人年龄无需账号、生日、健康档案或服务器上传。年龄和男女条件只用于前端阅读状态；若URL带这些参数，分享时允许清除。正文、静态分享页、打印、Markdown和JSON均保留阅读范围，不能只在网页版出现，导出后丢掉边界。人口元数据采用版本化附加结构，原六字段和稳定ID继续保留，旧调用者可以忽略新增字段。

### 14.3 新增部位时的必查问题

先问：哪些是跨年龄的普通清洁，哪些涉及发育，哪些涉及妊娠或性别相关药物限制，哪些随衰老或共病改变选择？再核来源是否支持这些分支。不是每个部位都必须给所有人群写同样多的条目；没有证据或未完成研究就保留空缺，而非补一段通用套话。

耳朵要区分耳廓、耳后、耳道、刚穿孔的伤口与已愈合耳洞，分别讨论清洁、材质、压力和感染。口腔的牙齿牙周与嘴唇黏膜各有唯一归属；换牙、正畸、牙齿美容与缺牙修复不能混为一种消费选择。儿童视力要分筛查、确诊、矫正、控制加深和日常预防；不把成人摘镜手术路径复制给未成年人。
