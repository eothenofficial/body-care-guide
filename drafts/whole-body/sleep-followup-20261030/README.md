## 复现

从项目根目录运行，需要Python 3.11及以上；实际阅读器行为测试另需Node.js：

```sh
python drafts/whole-body/sleep-followup-20261030/build_release.py
python -m unittest discover -s tests -v
python -m http.server 8132 --bind 127.0.0.1 --directory .draft-preview/sleep-followup-20261030/dist
```

本地浏览器入口 `http://127.0.0.1:8132/#/chapter/sleep`。离线HTML在 `.draft-preview/sleep-followup-20261030/dist/downloads/guide-offline.html`。`content/`仍是历史公开基线，不能直接用旧通用入口生成后宣称已包含本版。

`build_release.py`调用上一版lifestyle构建的数据函数，再整合exercise、meals、screen、recovery四组JSON。各组生成器是作者工作资料，最终以冻结后的JSON与独立复核SHA为准；后续重跑生成器须重新复核变化。构建按DOI/规范URL合并来源，统一引用、全部导出与接口。

## 本次范围

| 读者场景 | 稳定条目 | 主要限制 |
| --- | --- | --- |
| 睡前运动几小时/几点 | sleep-009 | 强度、时长、计划入睡；观察关联不当硬阈值 |
| 夜宵后睡不踏实 | sleep-010 | 大餐/点心/反流分开，保护必要降糖饮食计划 |
| 情绪、手机与蓝光 | sleep-011 | 收尾可试30–60分钟，不强迫情绪平静，不保证滤蓝光产品效果 |
| 失眠或熬夜次日 | sleep-012 | 先安全、休息、咖啡因总量与时点；补觉不定统一小时 |
| 少睡后是否训练 | sleep-013 | 警觉及失误后果优先，减量是保守选择而非个人安全保证 |
| 越想睡越清醒 | sleep-014 | 不盯钟考核20分钟，不自行大幅限制睡眠，防跌倒 |
| 感冒/抗过敏药被用来助眠 | sleep-015 | 慢性用途与其他适应证不同，复方重复成分与镇静叠加另核 |
| 夜间静止总想动腿 | sleep-016 | 症状线索不自诊，检查铁储备不自行补铁 |
