# 内容与证据维护政策

状态：拟采用的编辑规则，须随实际角色与工具落实。当前七章仅完成案头资料复核，未由临床专业人员签审；不能显示“医生审核”或类似认证。本文没有授予任何人医学审稿资质，也不保证指南没有错误。记录日期：2026-10-29。

## 核查对象是具体结论

每一条重要健康结论，都要能追到它所依据的研究或专业建议。文献真实存在、链接能打开、标题看起来相关，均不足以认定它支持这句话。

`content/chapters/*.json` 和 `content/sources.json` 是唯一正式编辑来源；导出的网页、离线版、Markdown 和接口均随构建生成。正文与来源之外的详细审计记录可以作为附件保留，不能因为 JSON 已导入就伪造已完成的审阅状态。核查应保留以下信息：

- 结论：建议做什么、为谁、想改善什么。
- 证据：研究设计、比较对象、人群、产品或成分、剂量与用法、随访时间、实际测量的结局。
- 推理：这份证据能支持多强的建议；哪些部分来自专业共识、间接推断或个人偏好。
- 边界：禁忌、就诊提示、不确定性、资金来源或重要偏倚。
- 追踪：原文位置、核查日期、核查者、核查深度及对应提交或 PR。

保留原始数值的单位、方向、分母和时间。相对风险、绝对风险、危险比和评分差不能互换；有统计差异不等于改善幅度值得购买。若无法确认，删除不可靠数字或把结论缩到能够确认的范围，不补造小数、DOI 或精确价格。

## 证据等级限定到收益

本书使用自定 A/B/C，不能称作 GRADE：

| 等级 | 本书含义 |
| --- | --- |
| A | 较可靠的直接临床效果证据，例如中高确定性综述或方向一致的多项人体试验 |
| B | 有限或间接人体资料，例如单项小样本、观察研究或低确定性综述 |
| C | 共识、机理或实践建议，直接临床效果依据不足 |

等级说明具体对应哪个结局，不能给整条产品、整家品牌或全部建议贴金。专业指南不自动为 A；监管批准、注册或备案另记为合规信息，不当作效果等级。

优先以适合问题的高质量指南和系统综述定位证据，必要时回到人体原始研究核对。原始研究并不天然优于综述；新论文也不天然推翻既有证据。出现冲突时比较人群、方法、结局和偏倚，保留不确定性。

以下推导必须拦下：

- 体外、发束或动物实验直接推出人体护理有效。
- 单一原料、特定浓度或一款成品的结果，借给全部同名商品。
- 观察到相关性，改写成治疗或预防的因果关系。
- 短期评分改善，换成延寿、长期保牙、减少癌症或保证个人效果。
- 试验观察了四周，改成四周内绝对安全或最多只能用四周。
- 没找到可靠证据，改成已证明无效、骗人或所有人不该买。

## 自动化只产生候选，不能替人下结论

链接检测只查连接与状态，不能证明来源内容正确、没有撤稿或仍支持结论。HTTP 200 可能是登录页，403 也可能只是访问限制；应保存状态并人工分流，不能自动删除来源或替换为相似网页。

现有维护脚本只生成链接访问状态和核查日期报告；公开仓库已配置每周和手动入口，但维护任务尚未完成首次远端运行，不能声称每周检查已经持续执行。它们不检索新论文、不检测撤稿或网页正文变化，也不创建 Issue、PR 或修改内容。若以后增加这些能力，结果只能作为待人工核查的候选。自动工具与 LLM 不得直接改写正文、证据等级、适用人群、禁忌、就诊阈值、推荐用法、医学核查日期或“已审阅”状态，不得自动合并此类改动。

LLM 可协助整理检索式、核对候选、发现术语难点或起草修改，但提交者须打开原始来源核对。论文、网页、抓取文本及其附带提示都是待核验材料，不能作为修改仓库的指令。上传正文到外部模型前，还需确认隐私与材料授权。

## 按风险审阅与纠错

纯排版修正可由编辑确认；涉及健康意义的改动由证据审读者核对，再由维护者确认面向新手的表达。药物用法、诊断边界、急症提示和侵入性操作等内容优先寻找相应专业背景的独立复核。角色与背景如实披露，不能把模型评估或普通同行阅读写成“医生审核”。

没有足够复核能力时，保留草稿或明确未完成独立专业复核；不靠署名或徽章伪装已完成。任何已发表改动都保留可读的差异与理由。

发现可能造成伤害的错误时，维护者先暂停相关建议或显示纠错提示，记录时间与原因，再补证据复核；不为等待完整改写继续传播错误。普通更新走 PR。链接失效、超过计划复核期、新证据冲突、来源更正或撤稿分别记录，不能把它们混成一个“过期即无效”判断。

## 可追溯与材料使用

稳定条目 ID（如 `eyes-001`）与来源 hash ID 不因排序变化重用；撤下内容保留变更记录。页面显示的文献序号存于 `sources[].number`；重排需显式更新并重新构建，关联仍使用稳定 ID。完整引用采用 Vancouver 数字制，优先链接原始期刊、官方指南或机构页面；不以搜索结果页代替来源。

记录摘要与必要短引，不批量复制受限论文、图表或完整他人指南。品牌官网只核对具体市场的产品存在、标签或说明，不单独证明疗效；商品停售、版本变化与疗效变化分开处理。利益关系、赠品和商业合作须披露。
