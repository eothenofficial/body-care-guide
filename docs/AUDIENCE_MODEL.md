# 阅读人群数据与筛选约定

这是可扩展的编辑数据，不是诊疗规则引擎。完整写作标准见[全书SOP](身体护理指南全书规划与调用SOP.md)第14节。

`audience_schema_version: "1.1.0"` 出现在该版book与manifest时，每条entry均须有以下附加结构。老版六字段接口继续保留。

```json
{
  "audience": {
    "age_groups": ["child", "teen"],
    "sexes": ["all"],
    "scope_note": "供学生与照护者阅读；具体方案按发育和检查条件判断。",
    "safety_pin": false
  }
}
```

| 键 | 含义与约束 |
| --- | --- |
| age_groups | 非空、无重复的导览分段：child 0–11；teen 12–17；adult 18–64；older 65+。不是治疗年龄阈值 |
| sexes | 非空数组，取all、female或male；all不得与其他值并存。通用内容匹配男女两种筛选 |
| scope_note | 非空纯文本，记录阅读范围和未覆盖的边界。医学判断留在有引文的正文 |
| safety_pin | 布尔值；仅人工标记急症入口；不绕过年龄、男女、症状、部位等任何筛选条件 |

读者可以输入0–120之间整数年龄，或选分段/18岁以下。具体年龄只映射段，不能自动生成剂量、禁忌或手术资格。年龄段与确切年龄两种输入需保持一致；应用按钮提交当前选择，非法年龄不应用。

筛选条件放在hash路由的age、band、sex参数中，并在章页、检索页、详情导航间保留。无需服务端、账号或生日。分享链接可能包含选中的年龄，使用清除筛选即可移除。

所有六字段正文的引用规则不变；人口结构作为附加元数据出现在JSON。交互详情、全书打印、静态分享页、构建生成与离线动态下载的Markdown都保留阅读范围。来源哈希ID和条目ID不能因人口分类或章节移动而改变。

缺元数据的旧版本仅按原成人稿兼容，不标为全龄。新版本由Python校验器要求每条完整填写；人工审读另核是否真的覆盖这个人群。工程校验无法证明其医学适用性。

男性或女性专属条目必须分别标 male / female，不能为了扩大覆盖率写 all。只有正文确实适用于双方、且双方均有具体行动的内容才标 all；例如共同避孕、备孕和性健康。怀孕、是否具有特定器官或可否用药不由选项推断。

实际筛选采用年龄与男女条件同时匹配。女性视图不显示男性专属卡片、单元、相邻建议或来源关联链接；男性同理。年龄不符的急症也不会插入结果。具体年龄的分段边界为0、12、18、65岁，确切年龄优先于年龄段参数。

章节、列表、收藏、侧栏计数、单元切换、相邻条目和打印页遵守同一规则。深链接打开不匹配建议时只显示范围提示，用户可主动清除筛选后阅读。混合单元被部分筛除时不展示可能包含其他人群建议的原导语。切换人群导致当前单元无匹配时，清除单元选择并回到本章匹配内容。

JSON、Markdown和完整离线文件是整本内容导出，明确标示不受当前筛选影响；不能将整本数据内仍存在异性条目误报成筛选视图泄漏。
