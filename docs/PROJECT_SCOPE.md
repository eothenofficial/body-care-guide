# 全书范围与五官试点

> 历史阶段记录。当前产品面向全年龄段、所有性别；本文件以下年轻人/五官/眼睛试点的描述保留最早决策背景，不代表现行范围。当前范围与写作规则以[全书SOP第1、32节](身体护理指南全书规划与调用SOP.md)、[身体位置目录](全书身体位置目录.md)和[当前构建说明](../drafts/whole-body/editorial-readability-20261030/README.md)为准。本轮未执行远端发布。


本项目面向中国年轻成年人，最终覆盖从头到脚的身体护理、常见困扰、产品判断与外观改善。当前五官篇用于验证内容方法，眼睛样章是这一轮最小试点。全书目录不由试点的部位数量决定。

## 三个层级

| 层级 | 当前决定 | 后续可调整 |
| --- | --- | --- |
| 全书 | 面向年轻人，覆盖全身，健康、舒适和自主选择的外观目标并存 | 篇目名称、总章数、合并拆分与阅读顺序 |
| 五官试点 | 保留已讨论的眼睛、鼻子、嘴唇、口腔、耳朵及面部相关选题 | 面部皮肤与其他跨部位内容的主要归属 |
| 眼睛样章 | 先跑通症状、护理、产品比较、消费场景与引用的一条完整阅读路径 | 条目规模、分组和具体标题，根据样章阅读与证据调整 |

头发和头皮保留在全书选题池，归属待定。本轮不将其算作五官篇必须完成的范围，也不删除既有资料。已发布的七模块66条是历史样稿，不是最终全书架构。

## 用多个入口找到同一份内容

正文保留“篇—章—单元—条目”的层次，条目有一个主要归属。症状、外观目标、产品和日常场景是交叉索引，帮助读者进入同一个条目。未来增加手足、躯干、私密护理等主题时，沿用这一原则。

例如“眼睛干涩”连接症状路径，“人工泪液”连接产品选择，“戴美瞳不舒服”连接佩戴异常与眼表路径。正文之间用稳定条目链接连接，避免复制三份结论。调整归属不重发旧ID。

美妆美容是全书的明确内容维度，不锁定为头面专属的两章。护理与病症、外观修饰、医疗操作分别按主要决策安排正文；其他入口提供短说明和跳转。妆效、舒适和便利是可评价的收益，不能一概称作心理安慰，也不能据此声称治疗作用。

## 眼睛样章的写作契约

每个单元有引言，先解释读者正在面对的决定。陌生词第一次出现时就近解释。条目标题包含具体动作或有条件的判断，不靠病名列表代替读者语言。

六字段继续使用：成本、说人话、收益、证据等级、来源、备注。正文包含适用条件、选择理由、执行动作及停止或升级处理的节点。重要就医条件不能藏在备注。

产品先确定目标和人群，再比较临床效果、使用负担、质量与安全、替代方案。证据不足、个体不适合、品牌溢价和明确风险分别判断，不全部归为“智商税”。具体型号必须另核对当地标签及直接证据，研究某成品不能替全部同类商品背书。

## 这轮的交付和验收

- 可阅读的眼睛完整样章，包含导览、递进单元、六字段与规范引用。
- 症状和产品可以检索，并能在相关条目之间跳转。
- 摘要、全文、机构患者教育与产品标签的读取深度分别记录。
- 记录旧条目保留、深化、拆分与新增的对应关系。
- 用现有构建器生成网页、离线HTML、Markdown与JSON，检查引用、ID及导出的一致性。

新医学文字保存在 `drafts/eye-pilot/`；本地预览由这些稿件与现有构建器生成。未完成临床专业签审，不能标为医生审核；不自动替换已发布的医学正文。构建测试证明数据与阅读功能可用，不证明每条医学结论已获临床验证。

这一轮不填满全书占位章节，不按月份承诺未经估算的工期。样章通过内容和阅读验收后，再把相同标准扩展到其他部位。
